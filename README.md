# Semester Wallet Agent

An autonomous budgeting agent for students, built with the Strands Agents SDK
for the **Agents for Humans Hackathon** (Everyday Agents track).

> 🚧 This README is a placeholder — will be filled in as the project develops.

## What it does

Semester Wallet watches a student's semester budget in the background —
tracking income, spending, and fixed costs — and only surfaces a decision
when one is actually needed (overspend risk, an Emergency-category spend,
a reallocation suggestion, an upcoming fixed cost).

## Status

Early development — architecture and data model in progress.
